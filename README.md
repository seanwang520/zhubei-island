# 竹北政策島

用 3D 小島瀏覽 2026 竹北市長參選人曾聖凱的政見。10 座島代表 10 項政策主題，共 43 個細項；每座島的造型取自一個竹北地標，例如高鐵新竹站、新瓦屋、新月沙灣。每座島外圍有一圈外環道路和一個入口，相鄰的島之間各有一座木棧橋。17 組搬運小人沿著外環道路和橋，在兩座島的入口之間來回搬運資源，每組代表兩項政見之間的一項協作。

> **非官方整理。** 本網站與候選人及其競選團隊無關。內容整理自公開新聞報導，每個細項都附有來源連結；報導內容皆為候選人自述的主張。「協作任務」中哪兩項政見互相搬運什麼，是整理者依政策關聯所做的示意，並非候選人原話。

靈感來自 [HEART 政策島](https://puma.taipei/heart-island)。

## 怎麼玩

- **點島嶼**或右側「政策主題」清單：看該主題的細項、說明與資料來源，以及島上地標的介紹與新聞連結。
- **點路上的小人**或「協作任務」清單：看他是誰、在哪兩座島之間搬什麼。
- **左上工具列**：
  - 清晨、白天、黃昏、夜晚：切換光線（夜晚燈籠、星星、車窗會亮起來）
  - 導覽：自動依序飛過 10 座島，每座停 7 秒；拖曳場景或點其他東西就會停
  - 名牌：顯示每位小人的身份
  - 搬運：顯示或隱藏搬運小人
  - 協作線：顯示全部 17 條路線
  - 音效：開關環境音（海浪；清晨、白天五色鳥；白天、黃昏台灣爺蟬；草蟬從早到晚），聲音在瀏覽器即時合成
  - 暫停：停止動畫
  - 全景：回到全島視角
- **電腦**：左鍵拖曳旋轉，右鍵拖曳平移，滾輪縮放。
- **手機**：單指拖曳移動，雙指縮放與旋轉。手機上會自動降低解析度、陰影與島上人數，並限制在 30fps。
- 網址加上 `#traffic`（主題 id）或 `#F6`（任務編號），可以直接開啟對應的島或任務。

## 在本機執行

網站使用 JavaScript 模組，瀏覽器不允許從 `file://` 載入，所以**不能直接雙擊 `index.html`**，要先開一個本機伺服器：

```bash
python3 -m http.server 8000
```

然後打開 <http://localhost:8000>。

## 檔案結構

純靜態網站，不需要建置。Three.js 0.160 透過 importmap 從 jsDelivr 載入。

| 檔案 | 內容 |
|---|---|
| `index.html` | 頁面入口 |
| `data/policies.js` | 政策主題、細項、協作任務與資料來源 |
| `js/scene.js` | 3D 場景：島嶼、木棧道、人物造型、光線 |
| `js/ui.js` | 介面：政策索引、細項卡、任務卡、開場導覽 |
| `js/main.js` | 把場景和介面接起來、自動導覽 |
| `js/sound.js` | 環境音效 |
| `og.png` | 分享到 LINE、Facebook 時的預覽圖 |
| `css/style.css` | 介面樣式 |

### 修改政見內容

所有內容都在 `data/policies.js`：

- `themes`：每座島的標題、顏色、地標（`landmark`）、摘要、細項（`items`）和相關主題（`links`）。島的 3D 造型在 `js/scene.js` 的 `BUILDERS`。
- `tasks`：協作任務。`from`、`to` 是兩座島的 id，`crew` 是兩位搬運人員的身份（可用的身份見 `js/scene.js` 的 `ROLES`），`source` 對應 `meta.sources` 的索引。
- `meta.sources`：所有引用的新聞報導。

### 重新產生分享預覽圖

網址加上 `?shot` 會隱藏介面、只留場景和標題卡，用 1200×630 的視窗截圖存成 `og.png` 即可。
